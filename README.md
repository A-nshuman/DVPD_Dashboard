# 🚀 College Innovation Hub Dashboard

![React](https://img.shields.io/badge/React-19.0-blue?style=for-the-badge&logo=react)
![Vite](https://img.shields.io/badge/Vite-6.0-purple?style=for-the-badge&logo=vite)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-4.0-38B2AC?style=for-the-badge&logo=tailwind-css)

A comprehensive analytics dashboard designed to centralize, track, and visualize the innovation ecosystem of the institute. This application monitors **Startup Incubation** and **Research Publications**, providing real-time insights into student and faculty achievements.

## 🌟 Key Features

- **Dual-Domain Tracking:** Seamlessly toggle between *Startup* and *Research* datasets.
- **Interactive Analytics:**
  - **Timeline Area Chart:** Visualizes project inception trends over years.
  - **Distribution Pie Chart:** Breaks down projects by domain (AI, Biotech, Robotics, etc.).
  - **Funding/Type Bar Chart:** Tracks funding stages (Startups) and project types (Research).
- **Advanced Search & Filtering:** Real-time filtering by project name, domain, and status.
- **Detailed Modals:** Deep-dive into specific projects, team members, and funding details.
- **Responsive Design:** Fully optimized layout for Desktop, Tablet, and Mobile views using Tailwind CSS.

## 🛠️ Tech Stack

- **Frontend:** React 19 (Vite)
- **Styling:** Tailwind CSS v4
- **Visualization:** Recharts
- **Icons:** Lucide React
- **Linting:** ESLint
